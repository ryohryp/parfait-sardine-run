# ADR-0001: 横スクロールアクションへコアゲームを転換する

- Status: Accepted
- Date: 2026-10-03
- Issue: #83

## Context

直近のプロトタイプは「パフェ作成 → 配達」と「工場エコロジー」を検証してきたが、ゲーム本体の操作そのものを主役にするため、コア体験を横スクロールアクションへ転換する。

既存リポジトリには React / TypeScript / Vite、Canvas ベースのゲーム実装、ネオン調の見た目、ジャンプ・攻撃などの資産がある。一方で既存ゲームコアはガチャ、ランキング、ミッション、ローグライト要素など多くの責務を抱えている。

## Decision

新しいコアゲームは、既存のメタ進行から独立した小さな vertical slice として実装する。

最初の1面で扱うのは次だけとする。

- 左右移動
- ジャンプ
- 近接攻撃
- 敵1種
- HP / 被弾 / 無敵時間
- 足場
- 横方向カメラ追従
- ステージゴール
- リトライ
- キーボード / タッチ操作

工場プロトタイプと旧ランナー実装はこの段階では削除しない。新プロトタイプの成立確認後に整理する。

## Game Identity

世界観は「パフェ × イワシ」の奇妙さを維持する。最初の敵は暴走イワシ、プレイヤーはパフェを守りながら進む配達役とし、ネオン調の見た目を継承する。

ただし、設定を増やすより先に操作感を検証する。

## Consequences

### Positive

- 1プレイの面白さを操作そのもので検証できる
- 旧メタ機能に引きずられず調整できる
- モバイルとデスクトップを同じループで検証できる
- 失敗時の原因が分かりやすい

### Negative

- 工場プロトタイプへの投資は一時的に休止する
- 既存 GameCanvas / game-core と新プロトタイプが並存する
- 面白さが確認できるまでランキングや育成を再利用しない

## Validation Gate

次の問いに実プレイで Yes と言えるまで機能を増やさない。

1. 走る・跳ぶだけでも気持ちいいか
2. 敵を見て攻撃する判断が発生するか
3. 被弾した原因が理解できるか
4. 1面クリア後にもう一度操作したくなるか
5. モバイル操作がストレスになっていないか
