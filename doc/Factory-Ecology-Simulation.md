# パフェ工場 × イワシ生態系 — Simulation Design v0.1

Issue: #75

## 目的

UIや演出を作る前に、少数のルールから複数の戦略・終状態・事故・回復が自然に生まれるかを検証する。

## Resource Flow

```text
原料 ──> 加工 ──> パフェ ──> 売上 ──> 維持費/設備
           │
           └──> 食品くず ──> イワシが食べる ──> 繁殖
                              │                 │
                              │                 └──> 混雑/詰まり ──> 生産低下
                              │
                              ├──> 捕獲 ──> 魚粉 ──> 売上
                              │
                              └──> 廃棄物削減 ──> 詰まり低減
```

## 3戦略

### 1. 排除型 / exclude

- フィルターでイワシを強く除去
- 通常廃棄設備で食品くずも処理
- 工場は安定しやすい
- 代償: 維持費、廃棄コスト、イワシ由来の副収入なし

### 2. 資源化型 / harvest

- 食品くずを一部 bait として利用
- イワシを一定数残しながら捕獲
- 捕獲イワシを魚粉として販売
- 代償: 生態系を完全には消せず、繁殖・詰まりの管理が必要

### 3. 共生型 / coexist

- イワシに食品くずを食べさせ、廃棄処理として利用
- 導線設計で詰まり圧を下げる
- 代償: 高密度化すると繁殖暴走・衛生コスト・詰まりリスクが急上昇

## Seedごとの環境差

各runは同じルールを使い、以下の連続値だけがseedで変わる。

- wasteRichness: 加工あたり食品くず量
- supplyVolatility: 原料供給の揺れ
- heatPressure: イワシ繁殖圧
- fishmealDemand: 魚粉市場価値
- cleanlinessPremium: 清潔な工場のパフェ販売価値

特定イベントが特定戦略を勝たせるハードカウンターは入れない。

## Emergent State Labels

最終状態を観測のために分類する。

- takeover: 詰まりが臨界状態
- sterile: イワシがほぼ消えた
- fishmeal: 捕獲・魚粉経済が成立
- symbiotic: イワシが廃棄処理を担いつつ制御可能
- managed_bloom: イワシ増加を許容しつつ詰まりを抑制
- recovered: 一度崩壊域に入った後に復旧
- mixed: 上記以外

ラベルはゲーム内ルールではなく、シミュレーション結果の観測用。

## Gate

1000 seeds × 3 strategies を比較して以下を満たすこと。

- 最大勝率 < 80%
- すべての戦略が少なくとも一部seedで勝つ
- 4種類以上の終状態が出る
- イワシが有益なrunが存在する
- collapse と recovery の両方が発生する
- 同じseedでも戦略によりvalueと終状態が変わる
